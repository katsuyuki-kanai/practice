## 1. フロントエンドとバックエンドの構成

### 1.1 アーキテクチャ概要

```
従来のWebアプリ（サーバーサイドレンダリング）：
┌──────────┐    リクエスト    ┌──────────────────────┐
│ ブラウザ  │ ──────────────→ │ サーバー（HTML生成）    │
│          │ ←────────────── │ Template + Controller  │
└──────────┘    HTML返却     └──────────────────────┘

モダンなWebアプリ（SPA + API）：
┌──────────────────┐    API呼出     ┌──────────────────┐
│ フロントエンド     │ ──────────→   │ バックエンド       │
│ (React/Vue)      │              │ (Spring Boot)     │
│ localhost:5173    │ ←──────────  │ localhost:8080    │
│                  │    JSON返却   │                  │
└──────────────────┘              └────────┬─────────┘
                                          │
                                  ┌───────┴────────┐
                                  │ データベース     │
                                  └────────────────┘
```

### 1.2 役割分担

| 項目 | フロントエンド | バックエンド |
|------|-------------|------------|
| **言語** | JavaScript/TypeScript | Java, Python, Go等 |
| **役割** | UIの表示・操作 | ビジネスロジック・データ管理 |
| **通信** | APIを呼び出す側 | APIを提供する側 |
| **データ形式** | JSON（受信・表示） | JSON（生成・返却） |
| **実行場所** | ブラウザ | サーバー |
| **フレームワーク** | React, Vue | Spring Boot, Express |

## 2. API通信の基本

### 2.1 Fetch APIによるGETリクエスト

```javascript
// 基本的なGETリクエスト
async function fetchUsers() {
    try {
        const response = await fetch('http://localhost:8080/api/users');
        
        if (!response.ok) {
            throw new Error(`HTTP error! status: ${response.status}`);
        }
        
        const users = await response.json();
        console.log(users);
        return users;
    } catch (error) {
        console.error('ユーザー取得に失敗:', error);
        throw error;
    }
}
```

### 2.2 POSTリクエスト（データ送信）

```javascript
// データの新規作成
async function createUser(userData) {
    const response = await fetch('http://localhost:8080/api/users', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
        },
        body: JSON.stringify(userData),
    });

    if (!response.ok) {
        const error = await response.json();
        throw new Error(error.message || 'ユーザー作成に失敗');
    }

    return await response.json();
}

// 使い方
const newUser = await createUser({
    name: '田中太郎',
    email: 'tanaka@example.com',
    age: 25,
});
```

### 2.3 CRUD操作の完全な例

```javascript
// APIクライアント
const API_BASE = 'http://localhost:8080/api';

const api = {
    // 一覧取得
    async getAll(resource) {
        const res = await fetch(`${API_BASE}/${resource}`);
        if (!res.ok) throw new Error(`GET /${resource} failed`);
        return res.json();
    },

    // 1件取得
    async getById(resource, id) {
        const res = await fetch(`${API_BASE}/${resource}/${id}`);
        if (!res.ok) throw new Error(`GET /${resource}/${id} failed`);
        return res.json();
    },

    // 新規作成
    async create(resource, data) {
        const res = await fetch(`${API_BASE}/${resource}`, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(data),
        });
        if (!res.ok) throw new Error(`POST /${resource} failed`);
        return res.json();
    },

    // 更新
    async update(resource, id, data) {
        const res = await fetch(`${API_BASE}/${resource}/${id}`, {
            method: 'PUT',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(data),
        });
        if (!res.ok) throw new Error(`PUT /${resource}/${id} failed`);
        return res.json();
    },

    // 削除
    async delete(resource, id) {
        const res = await fetch(`${API_BASE}/${resource}/${id}`, {
            method: 'DELETE',
        });
        if (!res.ok) throw new Error(`DELETE /${resource}/${id} failed`);
    },
};

// 使用例
const users = await api.getAll('users');
const user = await api.create('users', { name: '田中', email: 'tanaka@example.com' });
await api.update('users', user.id, { name: '田中太郎' });
await api.delete('users', user.id);
```

## 3. CORS（Cross-Origin Resource Sharing）

### 3.1 CORSとは

```
同一オリジンポリシー（Same-Origin Policy）：
ブラウザのセキュリティ機能。異なるオリジンへのリクエストを制限する。

オリジン = プロトコル + ホスト + ポート

例：
  http://localhost:5173  ← フロントエンド
  http://localhost:8080  ← バックエンド
  → ポートが違う = 異なるオリジン → ブロックされる！

┌──────────────┐                    ┌──────────────┐
│ フロントエンド  │ ── APIリクエスト ──→ │ バックエンド   │
│ :5173        │                    │ :8080        │
│              │ ← ❌ CORSエラー ── │              │
└──────────────┘                    └──────────────┘
  ブラウザが                         CORSヘッダーが
  レスポンスを                       ない場合
  ブロック
```

### 3.2 CORSエラーの例

```
ブラウザのコンソールに表示されるエラー：

Access to fetch at 'http://localhost:8080/api/users' 
from origin 'http://localhost:5173' has been blocked by CORS policy: 
No 'Access-Control-Allow-Origin' header is present 
on the requested resource.
```

### 3.3 プリフライトリクエスト

```
単純リクエスト（Simple Request）：
  GET, HEAD, POST（特定のContent-Typeのみ）

プリフライトが必要なリクエスト：
  PUT, DELETE, PATCH
  Content-Type: application/json
  カスタムヘッダーを含む

プリフライトの流れ：
┌──────────┐  ① OPTIONS /api/users     ┌──────────┐
│ ブラウザ   │ ───────────────────────→ │ サーバー   │
│          │  ② 許可ヘッダー返却         │          │
│          │ ←─────────────────────── │          │
│          │  ③ 本来のリクエスト(POST)    │          │
│          │ ───────────────────────→ │          │
│          │  ④ レスポンス               │          │
│          │ ←─────────────────────── │          │
└──────────┘                          └──────────┘
```

### 3.4 バックエンドでのCORS設定

#### Spring Boot の場合

```java
// 方法1: @CrossOrigin アノテーション（コントローラー単位）
@RestController
@RequestMapping("/api/users")
@CrossOrigin(origins = "http://localhost:5173")
public class UserController {
    @GetMapping
    public List<User> getUsers() {
        return userService.findAll();
    }
}

// 方法2: グローバル設定（推奨）
@Configuration
public class CorsConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOrigins("http://localhost:5173")
                .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                .allowedHeaders("*")
                .allowCredentials(true)
                .maxAge(3600);  // プリフライトのキャッシュ時間（秒）
    }
}
```

#### Express（Node.js）の場合

```javascript
const cors = require('cors');

// 方法1: 全オリジン許可（開発用）
app.use(cors());

// 方法2: 特定のオリジンのみ許可（本番用）
app.use(cors({
    origin: 'http://localhost:5173',
    methods: ['GET', 'POST', 'PUT', 'DELETE'],
    credentials: true,
}));
```

## 4. フロントエンドからのAPI連携（React での実装例）

### 4.1 ユーザー一覧表示

```jsx
import { useState, useEffect } from 'react';

function UserList() {
    const [users, setUsers] = useState([]);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    // コンポーネントの初回表示時にデータ取得
    useEffect(() => {
        fetchUsers();
    }, []);

    const fetchUsers = async () => {
        try {
            setLoading(true);
            const response = await fetch('/api/users');
            if (!response.ok) throw new Error('取得に失敗しました');
            const data = await response.json();
            setUsers(data);
        } catch (err) {
            setError(err.message);
        } finally {
            setLoading(false);
        }
    };

    if (loading) return <p>読み込み中...</p>;
    if (error) return <p>エラー: {error}</p>;

    return (
        <div>
            <h2>ユーザー一覧</h2>
            <table>
                <thead>
                    <tr>
                        <th>ID</th>
                        <th>名前</th>
                        <th>メール</th>
                    </tr>
                </thead>
                <tbody>
                    {users.map(user => (
                        <tr key={user.id}>
                            <td>{user.id}</td>
                            <td>{user.name}</td>
                            <td>{user.email}</td>
                        </tr>
                    ))}
                </tbody>
            </table>
        </div>
    );
}
```

### 4.2 新規登録フォーム

```jsx
function UserForm({ onSuccess }) {
    const [formData, setFormData] = useState({ name: '', email: '' });
    const [submitting, setSubmitting] = useState(false);
    const [error, setError] = useState(null);

    const handleChange = (e) => {
        const { name, value } = e.target;
        setFormData(prev => ({ ...prev, [name]: value }));
    };

    const handleSubmit = async (e) => {
        e.preventDefault();
        setSubmitting(true);
        setError(null);

        try {
            const response = await fetch('/api/users', {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify(formData),
            });

            if (!response.ok) {
                const err = await response.json();
                throw new Error(err.message || '登録に失敗しました');
            }

            const newUser = await response.json();
            setFormData({ name: '', email: '' });
            onSuccess?.(newUser);
        } catch (err) {
            setError(err.message);
        } finally {
            setSubmitting(false);
        }
    };

    return (
        <form onSubmit={handleSubmit}>
            <h2>ユーザー登録</h2>
            {error && <p style={{ color: 'red' }}>{error}</p>}
            <div>
                <label>名前:</label>
                <input name="name" value={formData.name} onChange={handleChange} required />
            </div>
            <div>
                <label>メール:</label>
                <input name="email" type="email" value={formData.email} onChange={handleChange} required />
            </div>
            <button type="submit" disabled={submitting}>
                {submitting ? '送信中...' : '登録'}
            </button>
        </form>
    );
}
```

## 5. 開発時のプロキシ設定

### 5.1 プロキシとは

```
CORSを回避する開発時テクニック：

プロキシなし：
┌────────────┐    異なるオリジン    ┌────────────┐
│ React :5173 │ ──── ❌ CORS ────→ │ API :8080   │
└────────────┘                    └────────────┘

プロキシあり：
┌────────────┐   同一オリジン   ┌────────────┐    転送    ┌────────────┐
│ React :5173 │ ──── ✅ ────→ │ Vite :5173  │ ────────→ │ API :8080   │
│             │               │ (プロキシ)    │           │             │
└────────────┘               └────────────┘           └────────────┘
  /api/users を                /api/** を
  リクエスト                    :8080 に転送
```

### 5.2 Vite（React/Vue）のプロキシ設定

```javascript
// vite.config.js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
    plugins: [react()],
    server: {
        port: 5173,
        proxy: {
            '/api': {
                target: 'http://localhost:8080',
                changeOrigin: true,
                // パスの書き換えが必要な場合
                // rewrite: (path) => path.replace(/^\/api/, '/api/v1'),
            },
        },
    },
});
```

```jsx
// プロキシ設定後は相対パスでAPIを呼び出せる
// ❌ CORS問題あり
const res = await fetch('http://localhost:8080/api/users');

// ✅ プロキシ経由（CORS問題なし）
const res = await fetch('/api/users');
```

## 6. 本番環境のデプロイ構成

### 6.1 典型的なデプロイパターン

```
パターン1: リバースプロキシ（Nginx）
┌──────────┐    ┌──────────────────┐    ┌──────────────┐
│ ブラウザ   │───→│ Nginx            │───→│ Spring Boot  │
│          │    │ /     → 静的Files │    │ :8080        │
│          │    │ /api/ → API       │    └──────────────┘
└──────────┘    └──────────────────┘

パターン2: Spring Bootに統合
┌──────────┐    ┌────────────────────────────┐
│ ブラウザ   │───→│ Spring Boot :8080           │
│          │    │ /     → static/（ビルド済み）  │
│          │    │ /api/ → REST API             │
└──────────┘    └────────────────────────────┘

パターン3: CDN + API（クラウド）
┌──────────┐    ┌─────────┐    ┌─────────────────┐
│ ブラウザ   │───→│ CDN     │    │ API Gateway     │
│          │    │ (静的)   │    │ → Lambda/ECS    │
└──────────┘    └─────────┘    └─────────────────┘
```

### 6.2 Nginx設定例

```nginx
server {
    listen 80;
    server_name example.com;

    # フロントエンド（ビルド済み静的ファイル）
    location / {
        root /var/www/html;
        index index.html;
        try_files $uri $uri/ /index.html;  # SPA対応
    }

    # APIリクエストをバックエンドに転送
    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 7. エラーハンドリングのベストプラクティス

### 7.1 統一的なエラーレスポンス

```java
// バックエンド（Spring Boot）: 統一エラーレスポンス
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ErrorResponse> handleNotFound(ResourceNotFoundException e) {
        ErrorResponse error = new ErrorResponse(
            "NOT_FOUND",
            e.getMessage(),
            LocalDateTime.now()
        );
        return ResponseEntity.status(404).body(error);
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ErrorResponse> handleValidation(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldErrors().stream()
            .map(err -> err.getField() + ": " + err.getDefaultMessage())
            .collect(Collectors.joining(", "));
        ErrorResponse error = new ErrorResponse("VALIDATION_ERROR", message, LocalDateTime.now());
        return ResponseEntity.badRequest().body(error);
    }
}
```

```javascript
// フロントエンド: エラーハンドリング
async function apiRequest(url, options = {}) {
    try {
        const response = await fetch(url, {
            headers: { 'Content-Type': 'application/json' },
            ...options,
        });

        if (!response.ok) {
            const errorData = await response.json().catch(() => null);
            
            switch (response.status) {
                case 400:
                    throw new Error(errorData?.message || '入力内容に誤りがあります');
                case 401:
                    // ログイン画面にリダイレクト
                    window.location.href = '/login';
                    return;
                case 403:
                    throw new Error('この操作を行う権限がありません');
                case 404:
                    throw new Error('リソースが見つかりません');
                case 500:
                    throw new Error('サーバーエラーが発生しました');
                default:
                    throw new Error(`予期しないエラー (${response.status})`);
            }
        }

        return await response.json();
    } catch (error) {
        if (error.name === 'TypeError') {
            throw new Error('サーバーに接続できません。ネットワークを確認してください');
        }
        throw error;
    }
}
```
