## 1. なぜフロントエンドフレームワークが必要か

### 1.1 素のJavaScriptの課題

```javascript
// ❌ 素のJavaScript：コードが複雑になりがち
// データが変更されたら、UIの更新を手動で行う必要がある

let todos = [];

function addTodo(text) {
    todos.push({ id: Date.now(), text, completed: false });
    renderTodos();      // 手動でUIを更新
    updateCounter();    // カウンターも更新
    saveToStorage();    // 保存も手動
}

function renderTodos() {
    const list = document.getElementById('todo-list');
    list.innerHTML = '';  // 全部消して再描画
    todos.forEach(todo => {
        const li = document.createElement('li');
        // ... 要素を作成して追加
        list.appendChild(li);
    });
}
// → アプリが大きくなると、管理が困難に
```

### 1.2 フレームワークが解決する問題

```
フレームワークのメリット：
├── 🔄 宣言的UI：「データが変わったらUIが自動更新」
├── 🧩 コンポーネント：UIを再利用可能な部品に分割
├── 📦 状態管理：アプリのデータを一元管理
├── 🛠️ 開発効率：ホットリロード、型チェック等
├── 🏗️ エコシステム：ルーティング、フォーム管理等
└── 👥 チーム開発：構造化されたコードで協業しやすい
```

### 1.3 主要なフレームワーク

| フレームワーク | 開発元 | 特徴 | シェア |
|-------------|--------|------|-------|
| **React** | Meta (Facebook) | 柔軟、大規模コミュニティ | ⭐⭐⭐⭐⭐ |
| **Vue** | コミュニティ | 学習しやすい、ドキュメント◎ | ⭐⭐⭐⭐ |
| **Angular** | Google | フルスタック、企業向け | ⭐⭐⭐ |
| **Svelte** | コミュニティ | コンパイラ方式、軽量 | ⭐⭐ |

## 2. React の基本

### 2.1 Reactとは

**React**は、**UIを構築するためのJavaScriptライブラリ**です。

```
Reactの特徴：
├── コンポーネントベース：UIを部品として構築
├── 仮想DOM：効率的なUI更新
├── JSX：HTMLライクな構文でUIを記述
├── 単方向データフロー：予測しやすいデータの流れ
└── 巨大なエコシステム：Next.js, React Router等
```

### 2.2 プロジェクトの作成

```bash
# Vite（推奨）でプロジェクト作成
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev
```

### 2.3 コンポーネントとJSX

```jsx
// 関数コンポーネント
function Greeting({ name }) {
    return (
        <div className="greeting">
            <h1>こんにちは、{name}さん！</h1>
            <p>Reactへようこそ</p>
        </div>
    );
}

// 使い方
function App() {
    return (
        <div>
            <Greeting name="田中" />
            <Greeting name="佐藤" />
        </div>
    );
}
```

```
JSXのルール：
├── className を使う（classではなく）
├── 閉じタグが必要：<img /> <br />
├── {} 内にJavaScript式を書ける
├── 単一のルート要素が必要（<div> または <> で囲む）
└── htmlFor を使う（forではなく）
```

### 2.4 State（状態管理）

```jsx
import { useState } from 'react';

function Counter() {
    // state の宣言: [現在の値, 更新関数] = useState(初期値)
    const [count, setCount] = useState(0);

    return (
        <div>
            <p>カウント: {count}</p>
            <button onClick={() => setCount(count + 1)}>+1</button>
            <button onClick={() => setCount(count - 1)}>-1</button>
            <button onClick={() => setCount(0)}>リセット</button>
        </div>
    );
}
```

### 2.5 リストのレンダリング

```jsx
function TodoList() {
    const [todos, setTodos] = useState([
        { id: 1, text: '買い物', completed: false },
        { id: 2, text: '掃除', completed: true },
    ]);

    return (
        <ul>
            {todos.map(todo => (
                <li key={todo.id} 
                    style={{ textDecoration: todo.completed ? 'line-through' : 'none' }}>
                    {todo.text}
                </li>
            ))}
        </ul>
    );
}
```

### 2.6 イベント処理とフォーム

```jsx
function TodoApp() {
    const [todos, setTodos] = useState([]);
    const [input, setInput] = useState('');

    const addTodo = (e) => {
        e.preventDefault();
        if (input.trim() === '') return;
        
        setTodos([...todos, { id: Date.now(), text: input, completed: false }]);
        setInput('');  // 入力欄をクリア
    };

    const toggleTodo = (id) => {
        setTodos(todos.map(todo =>
            todo.id === id ? { ...todo, completed: !todo.completed } : todo
        ));
    };

    const deleteTodo = (id) => {
        setTodos(todos.filter(todo => todo.id !== id));
    };

    return (
        <div>
            <h1>ToDo リスト</h1>
            <form onSubmit={addTodo}>
                <input 
                    value={input} 
                    onChange={(e) => setInput(e.target.value)}
                    placeholder="やることを入力..."
                />
                <button type="submit">追加</button>
            </form>
            <ul>
                {todos.map(todo => (
                    <li key={todo.id}>
                        <input 
                            type="checkbox" 
                            checked={todo.completed}
                            onChange={() => toggleTodo(todo.id)}
                        />
                        <span style={{ 
                            textDecoration: todo.completed ? 'line-through' : 'none' 
                        }}>
                            {todo.text}
                        </span>
                        <button onClick={() => deleteTodo(todo.id)}>削除</button>
                    </li>
                ))}
            </ul>
            <p>残り: {todos.filter(t => !t.completed).length}件</p>
        </div>
    );
}
```

## 3. Vue の基本

### 3.1 Vueとは

**Vue**は、**プログレッシブJavaScriptフレームワーク**です。

```
Vueの特徴：
├── テンプレート構文：HTMLに近い記法
├── リアクティブ：データ変更で自動的にUI更新
├── 学習しやすい：段階的に機能を追加
├── SFC：HTML/CSS/JSを1ファイルに
└── 優れたドキュメント：日本語対応
```

### 3.2 プロジェクトの作成

```bash
npm create vue@latest my-vue-app
cd my-vue-app
npm install
npm run dev
```

### 3.4 リアクティブな状態

```vue
<!-- Counter.vue -->
<script setup>
import { ref } from 'vue';

const count = ref(0);  // リアクティブな値

const increment = () => count.value++;
const decrement = () => count.value--;
const reset = () => count.value = 0;
</script>

<template>
    <div>
        <p>カウント: {{ count }}</p>
        <button @click="increment">+1</button>
        <button @click="decrement">-1</button>
        <button @click="reset">リセット</button>
    </div>
</template>
```

### 3.5 ToDoアプリ（Vue版）

```vue
<!-- TodoApp.vue -->
<script setup>
import { ref, computed } from 'vue';

const todos = ref([]);
const newTodo = ref('');

const remainingCount = computed(() => 
    todos.value.filter(t => !t.completed).length
);

const addTodo = () => {
    if (newTodo.value.trim() === '') return;
    todos.value.push({
        id: Date.now(),
        text: newTodo.value,
        completed: false
    });
    newTodo.value = '';
};

const toggleTodo = (todo) => {
    todo.completed = !todo.completed;
};

const deleteTodo = (id) => {
    todos.value = todos.value.filter(t => t.id !== id);
};
</script>

<template>
    <div>
        <h1>ToDo リスト</h1>
        <form @submit.prevent="addTodo">
            <input v-model="newTodo" placeholder="やることを入力..." />
            <button type="submit">追加</button>
        </form>
        <ul>
            <li v-for="todo in todos" :key="todo.id">
                <input 
                    type="checkbox" 
                    :checked="todo.completed"
                    @change="toggleTodo(todo)"
                />
                <span :style="{ textDecoration: todo.completed ? 'line-through' : 'none' }">
                    {{ todo.text }}
                </span>
                <button @click="deleteTodo(todo.id)">削除</button>
            </li>
        </ul>
        <p>残り: {{ remainingCount }}件</p>
    </div>
</template>
```

## 4. React vs Vue の比較

### 4.1 構文の比較

| 機能 | React | Vue |
|------|-------|-----|
| テンプレート | JSX（JavaScript内にHTML） | テンプレート構文（HTML内にJS） |
| 状態管理 | `useState(0)` | `ref(0)` |
| イベント | `onClick={handler}` | `@click="handler"` |
| 条件分岐 | `{condition && <div>...</div>}` | `v-if="condition"` |
| ループ | `{items.map(item => ...)}` | `v-for="item in items"` |
| 双方向バインド | `value + onChange` | `v-model` |
| スタイル | CSS Modules, styled-components | `<style scoped>` |

### 4.2 選定ガイド

```
React が向いているケース：
├── 大規模・複雑なアプリケーション
├── モバイルアプリも開発（React Native）
├── 柔軟性が求められるプロジェクト
├── 大規模なチーム・エコシステムの活用
└── JavaScript をフル活用したい

Vue が向いているケース：
├── 中小規模のプロジェクト
├── HTMLベースの開発に慣れたチーム
├── 学習コストを抑えたい
├── 既存プロジェクトへの段階的な導入
└── 日本語ドキュメントが充実
```
