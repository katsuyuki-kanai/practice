## 1. Spring Data JPA とは

### 1.1 JPA と Spring Data JPA

```
ORM（Object-Relational Mapping）：
  Javaのオブジェクト ←→ データベースのテーブル を自動変換

JPA（Java Persistence API）：
  ORMの標準仕様（インターフェース）

Hibernate：
  JPAの実装（最も有名）

Spring Data JPA：
  JPA をさらに簡単に使えるようにするSpringのライブラリ
  → リポジトリインターフェースだけでCRUDが完成！
```

### 1.2 従来のデータアクセスとの比較

```java
// ❌ 従来（JDBCで直接SQL）
public User findById(Long id) {
    String sql = "SELECT * FROM users WHERE id = ?";
    PreparedStatement ps = connection.prepareStatement(sql);
    ps.setLong(1, id);
    ResultSet rs = ps.executeQuery();
    if (rs.next()) {
        User user = new User();
        user.setId(rs.getLong("id"));
        user.setName(rs.getString("name"));
        // ... 多くのボイラープレートコード
        return user;
    }
    return null;
}

// ✅ Spring Data JPA
// インターフェースを定義するだけ！
public interface UserRepository extends JpaRepository<User, Long> {
    // findById, findAll, save, delete などが自動で使える！
}
```

## 3. エンティティの定義

### 3.1 基本的なエンティティ

```java
package com.example.demo.entity;

import jakarta.persistence.*;
import java.time.LocalDateTime;

@Entity                    // このクラスはDBテーブルに対応する
@Table(name = "users")     // テーブル名を指定
public class User {
    
    @Id                               // 主キー
    @GeneratedValue(strategy = GenerationType.IDENTITY)  // 自動採番
    private Long id;
    
    @Column(nullable = false, length = 100)  // NOT NULL、最大100文字
    private String name;
    
    @Column(unique = true, nullable = false)  // ユニーク制約
    private String email;
    
    @Column
    private Integer age;
    
    @Column(name = "created_at")
    private LocalDateTime createdAt;
    
    @Column(name = "updated_at")
    private LocalDateTime updatedAt;
    
    // JPA用デフォルトコンストラクタ（必須）
    public User() {}
    
    public User(String name, String email, Integer age) {
        this.name = name;
        this.email = email;
        this.age = age;
    }
    
    // ライフサイクルコールバック
    @PrePersist  // 保存前に自動実行
    protected void onCreate() {
        this.createdAt = LocalDateTime.now();
        this.updatedAt = LocalDateTime.now();
    }
    
    @PreUpdate  // 更新前に自動実行
    protected void onUpdate() {
        this.updatedAt = LocalDateTime.now();
    }
    
    // getter / setter（省略）
    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
    public Integer getAge() { return age; }
    public void setAge(Integer age) { this.age = age; }
    public LocalDateTime getCreatedAt() { return createdAt; }
    public LocalDateTime getUpdatedAt() { return updatedAt; }
}
```

### 3.2 エンティティとテーブルの対応

```
@Entity User クラス
         ↕ 自動マッピング
users テーブル
┌────┬──────────┬────────────────┬─────┬───────────────────┐
│ id │   name   │     email      │ age │    created_at     │
├────┼──────────┼────────────────┼─────┼───────────────────┤
│  1 │ 田中太郎  │ tanaka@ex.com  │  25 │ 2025-01-01 10:00 │
│  2 │ 佐藤花子  │ sato@ex.com    │  30 │ 2025-01-02 11:00 │
└────┴──────────┴────────────────┴─────┴───────────────────┘
```

### 3.3 主なアノテーション

| アノテーション | 説明 |
|-------------|------|
| `@Entity` | エンティティクラスを宣言 |
| `@Table(name)` | テーブル名を指定 |
| `@Id` | 主キー |
| `@GeneratedValue` | 自動採番 |
| `@Column` | カラムの設定（nullable, unique, length） |
| `@PrePersist` | INSERT前のコールバック |
| `@PreUpdate` | UPDATE前のコールバック |

## 4. リポジトリの作成

### 4.1 基本のリポジトリ

```java
package com.example.demo.repository;

import com.example.demo.entity.User;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;
import java.util.List;

@Repository
public interface UserRepository extends JpaRepository<User, Long> {
    // JpaRepository を継承するだけで基本的なCRUDメソッドが使える！
    
    // ↓ これらのメソッドは自動的に使用可能（実装不要）
    // findAll()       - 全件取得
    // findById(id)    - 1件取得
    // save(entity)    - 保存（INSERT/UPDATE）
    // deleteById(id)  - 削除
    // count()         - 件数
    // existsById(id)  - 存在確認
}
```

### 4.2 カスタムクエリメソッド

**メソッド名からクエリを自動生成**する機能があります。

```java
public interface UserRepository extends JpaRepository<User, Long> {
    
    // メソッド名規則で自動生成されるクエリ
    List<User> findByName(String name);
    // → SELECT * FROM users WHERE name = ?
    
    List<User> findByAgeGreaterThan(int age);
    // → SELECT * FROM users WHERE age > ?
    
    List<User> findByNameContaining(String keyword);
    // → SELECT * FROM users WHERE name LIKE '%keyword%'
    
    List<User> findByAgeBetween(int min, int max);
    // → SELECT * FROM users WHERE age BETWEEN ? AND ?
    
    List<User> findByNameAndAge(String name, int age);
    // → SELECT * FROM users WHERE name = ? AND age = ?
    
    Optional<User> findByEmail(String email);
    // → SELECT * FROM users WHERE email = ?
    
    List<User> findByOrderByNameAsc();
    // → SELECT * FROM users ORDER BY name ASC
    
    long countByAgeGreaterThan(int age);
    // → SELECT COUNT(*) FROM users WHERE age > ?
    
    boolean existsByEmail(String email);
    // → SELECT EXISTS(SELECT 1 FROM users WHERE email = ?)
}
```

### 4.3 クエリメソッド命名規則

| キーワード | 例 | SQL |
|-----------|-----|-----|
| `findBy` | `findByName` | `WHERE name = ?` |
| `And` | `findByNameAndAge` | `WHERE name = ? AND age = ?` |
| `Or` | `findByNameOrEmail` | `WHERE name = ? OR email = ?` |
| `Between` | `findByAgeBetween` | `WHERE age BETWEEN ? AND ?` |
| `LessThan` | `findByAgeLessThan` | `WHERE age < ?` |
| `GreaterThan` | `findByAgeGreaterThan` | `WHERE age > ?` |
| `Like` | `findByNameLike` | `WHERE name LIKE ?` |
| `Containing` | `findByNameContaining` | `WHERE name LIKE '%?%'` |
| `OrderBy` | `findByOrderByNameAsc` | `ORDER BY name ASC` |
| `IsNull` | `findByEmailIsNull` | `WHERE email IS NULL` |

### 4.4 @Queryによるカスタムクエリ

```java
public interface UserRepository extends JpaRepository<User, Long> {
    
    // JPQLクエリ
    @Query("SELECT u FROM User u WHERE u.age >= :minAge ORDER BY u.name")
    List<User> findAdults(@Param("minAge") int minAge);
    
    // ネイティブSQLクエリ
    @Query(value = "SELECT * FROM users WHERE name LIKE %:keyword%", 
           nativeQuery = true)
    List<User> searchByName(@Param("keyword") String keyword);
}
```

## 5. CRUD操作の完全な実装

### 5.1 Service層

```java
package com.example.demo.service;

import com.example.demo.entity.User;
import com.example.demo.exception.ResourceNotFoundException;
import com.example.demo.repository.UserRepository;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import java.util.List;

@Service
@Transactional  // トランザクション管理
public class UserService {
    
    private final UserRepository userRepository;
    
    public UserService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }
    
    // 全件取得
    @Transactional(readOnly = true)
    public List<User> findAll() {
        return userRepository.findAll();
    }
    
    // 1件取得
    @Transactional(readOnly = true)
    public User findById(Long id) {
        return userRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("User", id));
    }
    
    // 作成
    public User create(User user) {
        // メールの重複チェック
        if (userRepository.existsByEmail(user.getEmail())) {
            throw new IllegalArgumentException("このメールアドレスは既に使用されています");
        }
        return userRepository.save(user);
    }
    
    // 更新
    public User update(Long id, User updateData) {
        User existing = findById(id);
        existing.setName(updateData.getName());
        existing.setEmail(updateData.getEmail());
        existing.setAge(updateData.getAge());
        return userRepository.save(existing);
    }
    
    // 削除
    public void delete(Long id) {
        if (!userRepository.existsById(id)) {
            throw new ResourceNotFoundException("User", id);
        }
        userRepository.deleteById(id);
    }
    
    // 検索
    @Transactional(readOnly = true)
    public List<User> searchByName(String keyword) {
        return userRepository.findByNameContaining(keyword);
    }
}
```

### 5.2 Controller層

```java
package com.example.demo.controller;

import com.example.demo.entity.User;
import com.example.demo.service.UserService;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import java.util.List;

@RestController
@RequestMapping("/api/users")
public class UserController {
    
    private final UserService userService;
    
    public UserController(UserService userService) {
        this.userService = userService;
    }
    
    @GetMapping
    public List<User> getAllUsers() {
        return userService.findAll();
    }
    
    @GetMapping("/{id}")
    public User getUserById(@PathVariable Long id) {
        return userService.findById(id);
    }
    
    @PostMapping
    public ResponseEntity<User> createUser(@RequestBody User user) {
        User created = userService.create(user);
        return ResponseEntity.status(HttpStatus.CREATED).body(created);
    }
    
    @PutMapping("/{id}")
    public User updateUser(@PathVariable Long id, @RequestBody User user) {
        return userService.update(id, user);
    }
    
    @DeleteMapping("/{id}")
    public ResponseEntity<Void> deleteUser(@PathVariable Long id) {
        userService.delete(id);
        return ResponseEntity.noContent().build();
    }
    
    @GetMapping("/search")
    public List<User> searchUsers(@RequestParam String name) {
        return userService.searchByName(name);
    }
}
```

## 6. テーブル間のリレーション

### 6.1 1対多（One-to-Many）

```java
// 部署エンティティ（1側）
@Entity
@Table(name = "departments")
public class Department {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    private String name;
    
    @OneToMany(mappedBy = "department", cascade = CascadeType.ALL)
    private List<Employee> employees = new ArrayList<>();
}

// 社員エンティティ（多側）
@Entity
@Table(name = "employees")
public class Employee {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    private String name;
    
    @ManyToOne
    @JoinColumn(name = "department_id")  // 外部キー
    private Department department;
}
```
